# 家計簿・資産の連携

v1.11.0。生活メニューの末尾から開く。NASのhousehold-ledger v0.3.0以上と、mini-app配信元を許可する `MOBILE_ALLOWED_ORIGINS` が必要。稼働中のv1.9.1とNAS v0.2.0はまだ入れ替えていない。

## 画面と計算

NASの同じ台帳APIを使い、予算・支出・残額・貸方残、借方・貸方・摘要を表示する。週間統計は借方合計、精算表は借方の現金以外、貸方週別は元明細の週に処理済み額を表示する。別月日付と繰越の集計、マイナス金額、独立した月予算はNASの共通ルールに従う。

固定資産は年間台帳。借方が償却中、貸方が償却済み。月次借方の「固定資産台帳に繰越」で充当し、月残額と未回収元本が同時に減る。資産登録だけでは支出に計上しない。履歴・編集・精算の操作は明細単位で行う。

画面はShadow DOMで既存機能と分離する。台帳表示・編集コードはhousehold-ledger v0.2.1を基にし、mini-appのグレー・角丸なしのボタンと配信パスに合わせる。以降は両リポジトリのAPI契約・業務表示を合わせて更新する。

## 接続と端末保存

接続先はHTTPSのOriginを入力する。パス・認証情報・クエリ・フラグメントは不可。localhostだけHTTPを許可し、合成テストに使用する。`/api/mobile/info` でprotocol=1を確認した後、本人用アクセスキーをBearerで送る。Cookieは送らず、キーはメモリー内だけに保持する。

画面を再読込みするとキーの再入力が必要。取得済み月と送信待ちは保持される。「保存済みの画面を見る」で月を切り替えて閲覧・入力でき、「再接続」で同じNASへ送る。接続解除で端末データを削除しない。

保存領域はmini-app配信パス＋NAS接続先で区別する。既存日用品のIndexedDBやOCRキャッシュには触れない。UUIDと編集開始時revisionを送信前に保存し、Web Locksで複数タブを直列化する。Web Locks非対応環境では保存を停止して更新案内を出す。応答が失われても同じUUIDで再送する。

NAS受付後はNASの永続送信待ち・操作履歴でSheets反映を追跡する。競合は自動上書きせず、端末またはNASの同期状況に保持する。未送信が残る間は接続先変更を止める。API応答やキーはService Workerの静的キャッシュに入れない。

## 検証

`tests/ledger.mjs` は別のhousehold-ledgerチェックアウトにある合成APIサーバーを起動する。実NAS・実Google・本人のブラウザープロファイルは使用しない。合成DB・専用プロファイル・結果JSON・画面画像はそれぞれのタスクフォルダーに保持し、削除しない。

2026年11月15日、Windowsの専用Edgeプロファイルで次を確認した。

- 別Originでの接続、月次集計と摘要。
- 予算残10,000から資産へ3,000を充当し残7,000、資産が償却済みに移動。
- 貸方3,500の全額処理、借方マイナス120の返金。
- 圏外入力、再読込み、保存済み月の切替、同一UUIDでの再送。
- NASで受付後に応答だけを失い、再送しても明細が重複しない。
- 2タブで同時入力しても両方保存・反映される。
- 編集中の他端末更新に対して古い入力を保持し、上書きを拒否する。
- キーの永続保存なし、認証Cookieなし、幅390pxの横はみ出しなし、未捕捉JS例外0。

再実行の例（依存導入済みのタスク内チェックアウトで実行）：

```powershell
$env:LEDGER_TEST_ROOT = (Resolve-Path '../household-ledger').Path
npm run test:ledger
npm run check
npm run build:preserve
```

## 配布・適用の保留

`npm run build:preserve` は `dist-preserved-1.11.0-*` に配信専用ファイルだけを新規作成し、既存distや配信ファイルを削除しない。GitHubの隔離された検査環境では、テスト用データだけを使って既存機能と家計簿連携を検証する。実NAS・実Googleや本人のファイルには接続しない。NASのコンテナ入替えが保留の間は、互換性のない新版を既存公開URLへ上書きしない。

適用再開時はNAS側API→mini-appの順に更新し、既存PWAと同じURL・id・scopeを使う。旧Service Workerキャッシュは今回の準備版では保持する。アイコン、既存機能、日用品の保存領域を維持する。外出先は端末が家計簿のHTTPSホストへ接続できるVPN等の経路が別途必要で、実機確認は配備後に行う。
